5. Tomcat Installation and Configuration

5.1 What Tomcat does

Tomcat is a web server and Servlet container. It listens for HTTP requests, finds the mapped Servlet, creates request/response objects, calls methods such as doGet() or doPost(), and returns the response to the browser.

5.2 Extract Tomcat

For this course, keep Tomcat under the dependencies folder, for example:

C:\Sapir_JavaCourse_14\Dependencies\apache-tomcat-10.1.59

If your actual Tomcat version is different, replace the version number in the commands.

5.3 Important directories

DirectoryPurpose
binStartup and shutdown scripts.
libTomcat libraries, including servlet-api.jar.
webappsDeployed web applications.
logsServer logs and error information.
confTomcat configuration.

5.4 Use a Batch File to Restart Tomcat

For this course, use the following simple batch-file practice instead of manually changing into Tomcat's bin directory each time.

Create a file such as:

restart_tomcat.bat

Place the following commands inside it:

set "CATALINA_HOME=C:\Sapir_JavaCourse_14\Dependencies\apache-tomcat-10.1.59"

call "%CATALINA_HOME%\bin\shutdown.bat"

call "%CATALINA_HOME%\bin\startup.bat"

This does three things:

  1. CATALINA_HOME stores the location of the Tomcat installation.
  2. shutdown.bat stops Tomcat if it is already running.
  3. startup.bat starts Tomcat again.
Why use call? Because shutdown.bat and startup.bat are batch files. Using call lets Windows return to your own batch file after each Tomcat script finishes.
Why write set "CATALINA_HOME=..." with quotes in this form? The quotes protect the path without becoming part of the variable value. This is the standard safe Windows batch syntax.

5.5 Run Tomcat

Double-click restart_tomcat.bat, or run it from Command Prompt:

restart_tomcat.bat

Then verify Tomcat in the browser:

http://localhost:8080

When testing the ServletDemo later, open:

http://localhost:8080/ServletDemo/hello?name=Yossef

You should see the Servlet greeting and the server time.

5.6 Stop Tomcat Only

If you want to stop Tomcat without restarting it:

package demo;

import java.io.IOException;
import java.io.PrintWriter;

import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

@WebServlet("/hello")
public class HelloServlet extends HttpServlet {

    @Override
    protected void doGet(
            HttpServletRequest request,
            HttpServletResponse response) throws IOException {

        String name = request.getParameter("name");

        if (name == null || name.isBlank()) {
            name = "Guest";
        }

        response.setContentType("text/plain;charset=UTF-8");

        PrintWriter out = response.getWriter();
        out.println("Hello, " + name + "!");
    }
}

10. Create DatabaseConnection.java

File: src\demo\DatabaseConnection.java

package demo;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class DatabaseConnection {

    private static final String URL =
            "jdbc:mysql://localhost:3306/to_do_list"
            + "?useSSL=false"
            + "&serverTimezone=UTC"
            + "&allowPublicKeyRetrieval=true";

    private static final String USER = "todo_app";
    private static final String PASSWORD = "ChangeThisPassword";

    private DatabaseConnection() {
    }

    public static Connection getConnection()
            throws SQLException {

        return DriverManager.getConnection(
                URL, USER, PASSWORD);
    }
}

Modern MySQL Connector/J automatically registers itself with JDBC. Normally you do not need to call Class.forName(...).

11. Create TodoServlet.java

File: src\demo\TodoServlet.java

For this first project, one Servlet handles all operations. This keeps the HTTP and JDBC flow visible to students. A later exercise can refactor SQL into a DAO class.

package demo;

import java.io.IOException;
import java.io.PrintWriter;
import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

@WebServlet("/todo")
public class TodoServlet extends HttpServlet {

    @Override
    protected void doGet(
            HttpServletRequest request,
            HttpServletResponse response)
            throws ServletException, IOException {

        response.setContentType(
                "text/html;charset=UTF-8");

        String sql =
                "SELECT id, title, completed "
              + "FROM todo "
              + "ORDER BY id DESC";

        try (
            Connection connection =
                    DatabaseConnection.getConnection();

            PreparedStatement statement =
                    connection.prepareStatement(sql);

            ResultSet resultSet =
                    statement.executeQuery()
        ) {
            PrintWriter out = response.getWriter();

            printPageStart(out);
            printAddForm(out);
            printTodoTable(out, resultSet);
            printPageEnd(out);

        } catch (SQLException e) {
            throw new ServletException(
                    "Database error while loading tasks.",
                    e);
        }
    }

    @Override
    protected void doPost(
            HttpServletRequest request,
            HttpServletResponse response)
            throws ServletException, IOException {

        request.setCharacterEncoding("UTF-8");

        String action =
                request.getParameter("action");

        try {
            if ("add".equals(action)) {
                addTodo(request);

            } else if ("toggle".equals(action)) {
                toggleTodo(request);

            } else if ("delete".equals(action)) {
                deleteTodo(request);
            }

        } catch (SQLException |
                 NumberFormatException e) {

            throw new ServletException(
                    "Database error while updating tasks.",
                    e);
        }

        // Post / Redirect / Get
        response.sendRedirect(
                request.getContextPath() + "/todo");
    }

    private void addTodo(HttpServletRequest request)
            throws SQLException {

        String title =
                request.getParameter("title");

        if (title == null || title.isBlank()) {
            return;
        }

        String sql =
                "INSERT INTO todo (title) VALUES (?)";

        try (
            Connection connection =
                    DatabaseConnection.getConnection();

            PreparedStatement statement =
                    connection.prepareStatement(sql)
        ) {
            statement.setString(1, title.trim());
            statement.executeUpdate();
        }
    }

    private void toggleTodo(HttpServletRequest request)
            throws SQLException {

        int id = Integer.parseInt(
                request.getParameter("id"));

        String sql =
                "UPDATE todo "
              + "SET completed = NOT completed "
              + "WHERE id = ?";

        try (
            Connection connection =
                    DatabaseConnection.getConnection();

            PreparedStatement statement =
                    connection.prepareStatement(sql)
        ) {
            statement.setInt(1, id);
            statement.executeUpdate();
        }
    }

    private void deleteTodo(HttpServletRequest request)
            throws SQLException {

        int id = Integer.parseInt(
                request.getParameter("id"));

        String sql =
                "DELETE FROM todo WHERE id = ?";

        try (
            Connection connection =
                    DatabaseConnection.getConnection();

            PreparedStatement statement =
                    connection.prepareStatement(sql)
        ) {
            statement.setInt(1, id);
            statement.executeUpdate();
        }
    }

    private void printPageStart(PrintWriter out) {

        out.println("<!DOCTYPE html>");
        out.println("<html lang='en'>");
        out.println("<head>");
        out.println("<meta charset='UTF-8'>");

        out.println(
            "<meta name='viewport' "
          + "content='width=device-width, "
          + "initial-scale=1.0'>");

        out.println(
            "<title>My To-Do List</title>");

        out.println("<style>");

        out.println("""
            body {
                font-family: Arial, sans-serif;
                max-width: 760px;
                margin: 40px auto;
                padding: 0 16px;
                background: #f4f6f8;
            }

            .card {
                background: white;
                padding: 24px;
                border-radius: 10px;
                box-shadow: 0 2px 10px #ccc;
            }

            .add-form {
                display: flex;
                gap: 8px;
                margin-bottom: 20px;
            }

            .add-form input[type=text] {
                flex: 1;
                padding: 10px;
            }

            button {
                padding: 8px 12px;
                cursor: pointer;
            }

            table {
                width: 100%;
                border-collapse: collapse;
            }

            th, td {
                padding: 10px;
                border-bottom: 1px solid #ddd;
                text-align: left;
            }

            .done {
                text-decoration: line-through;
                color: #777;
            }

            .inline {
                display: inline;
            }
            """);

        out.println("</style>");
        out.println("</head>");
        out.println("<body>");
        out.println("<div class='card'>");
        out.println("<h1>My To-Do List</h1>");
    }

    private void printAddForm(PrintWriter out) {

        out.println("""
            <form class='add-form'
                  action='todo'
                  method='post'>

                <input type='hidden'
                       name='action'
                       value='add'>

                <input type='text'
                       name='title'
                       placeholder='Enter a new task'
                       maxlength='255'
                       required>

                <button type='submit'>
                    Add
                </button>
            </form>
            """);
    }

    private void printTodoTable(
            PrintWriter out,
            ResultSet resultSet)
            throws SQLException {

        out.println("<table>");

        out.println("""
            <tr>
                <th>Status</th>
                <th>Task</th>
                <th>Delete</th>
            </tr>
            """);

        while (resultSet.next()) {

            int id =
                    resultSet.getInt("id");

            String title =
                    resultSet.getString("title");

            boolean completed =
                    resultSet.getBoolean("completed");

            String cssClass =
                    completed ? "done" : "";

            out.println("<tr>");

            // Toggle completed state
            out.println("<td>");

            out.println(
                "<form class='inline' "
              + "action='todo' method='post'>");

            out.println(
                "<input type='hidden' "
              + "name='action' "
              + "value='toggle'>");

            out.println(
                "<input type='hidden' "
              + "name='id' value='"
              + id + "'>");

            out.println(
                "<button type='submit'>"
              + (completed ? "Undo" : "Done")
              + "</button>");

            out.println("</form>");
            out.println("</td>");

            // Task title
            out.println(
                "<td class='" + cssClass + "'>"
              + escapeHtml(title)
              + "</td>");

            // Delete
            out.println("<td>");

            out.println(
                "<form class='inline' "
              + "action='todo' method='post'>");

            out.println(
                "<input type='hidden' "
              + "name='action' "
              + "value='delete'>");

            out.println(
                "<input type='hidden' "
              + "name='id' value='"
              + id + "'>");

            out.println(
                "<button type='submit'>"
              + "Delete"
              + "</button>");

            out.println("</form>");
            out.println("</td>");

            out.println("</tr>");
        }

        out.println("</table>");
    }

    private void printPageEnd(PrintWriter out) {

        out.println("</div>");
        out.println("</body>");
        out.println("</html>");
    }

    private String escapeHtml(String text) {

        return text
                .replace("&", "&amp;")
                .replace("<", "&lt;")
                .replace(">", "&gt;")
                .replace("\"", "&quot;")
                .replace("'", "&#39;");
    }
}
Java 21 feature: The """ blocks are Java text blocks. They are useful when writing multi-line HTML/CSS strings.

11.1 Why PreparedStatement?

Do not concatenate user input into SQL:

// Do not do this:
String sql =
    "INSERT INTO todo(title) VALUES ('"
    + title + "')";

Use placeholders:

String sql =
    "INSERT INTO todo (title) VALUES (?)";

PreparedStatement statement =
    connection.prepareStatement(sql);

statement.setString(1, title);

This handles values correctly and is an essential defense against SQL injection.

11.2 Why escapeHtml()?

A task title comes from the user. Before putting that text inside an HTML response, HTML special characters should be escaped so the title is displayed as text rather than interpreted as HTML markup.

14. Understand the Full Request Flow

14.1 Display tasks - GET

  1. The browser requests GET /ServletJdbcTodo/todo.
  2. Tomcat matches /todo to @WebServlet("/todo").
  3. Tomcat calls TodoServlet.doGet().
  4. The Servlet calls DatabaseConnection.getConnection().
  5. JDBC opens a connection to MySQL.
  6. The Servlet runs the SELECT query.
  7. JDBC returns a ResultSet.
  8. The Servlet loops over the rows and writes HTML.
  9. Tomcat sends the HTTP response.
  10. The browser renders the HTML page.

14.2 Add a task - POST

  1. The user enters a title and clicks Add.
  2. The browser sends a POST request with action=add and title=....
  3. Tomcat calls doPost().
  4. The Servlet reads request parameters.
  5. The Servlet executes an INSERT with PreparedStatement.
  6. The Servlet calls sendRedirect().
  7. The browser sends a fresh GET request.
  8. The new task appears.

14.3 Post/Redirect/Get

Redirecting after a successful POST prevents browser refresh from accidentally repeating the previous insert/update/delete operation.

16. Troubleshooting

package jakarta.servlet does not exist

The Servlet API is missing from the compiler classpath. Include:

...\apache-tomcat-10.1.59\lib\servlet-api.jar

HTTP 404

  • Verify the app is under Tomcat webapps.
  • Verify TodoServlet.class is under WEB-INF\classes\demo.
  • Verify the annotation says @WebServlet("/todo").
  • Verify the URL is /ServletJdbcTodo/todo.

HTTP 500

The Servlet was found, but code failed while running. Read the Tomcat console and files under the logs directory.

No suitable driver found

Make sure the MySQL Connector JAR is in:

WEB-INF\lib\mysql-connector-j-....jar

Access denied for user

Check the MySQL username, password, host and privileges.

Unknown database 'to_do_list'

Create the database or correct the JDBC URL.

Communications link failure

Verify the MySQL service is running and the server/port are correct.

Old code still appears after compiling

Compilation changes the project copy of the .class files. Make sure the newly compiled files are also the ones inside the deployed webapps\ServletJdbcTodo\WEB-INF\classes folder. During a first manual tutorial, restarting Tomcat after redeployment removes ambiguity.

18.13 GitHub authentication

GitHub no longer accepts your normal account password for command-line Git operations over HTTPS.

When authentication is requested, the recommended approach is usually to sign in through the browser or use Git Credential Manager. If Git opens a browser login window:

  1. Sign in to GitHub.
  2. Authorize Git Credential Manager if requested.
  3. Return to the terminal.
  4. The push should continue automatically.
If you see:
remote: Invalid username or token.
Password authentication is not supported for Git operations.

Do not enter your normal GitHub password. Use browser authentication, Git Credential Manager, or a Personal Access Token.

18.14 Personal Access Token - alternative method

If browser authentication is not available, create a GitHub Personal Access Token and use that token instead of your password.

  1. Open GitHub.
  2. Open Settings.
  3. Open Developer settings.
  4. Open Personal access tokens.
  5. Create a token with permission to access repositories.
  6. Copy the token immediately and store it securely.

When Git asks for credentials:

Username: YOUR_GITHUB_USERNAME
Password: YOUR_PERSONAL_ACCESS_TOKEN
Never upload a Personal Access Token to GitHub, put it in Java source code, or share it with students.
